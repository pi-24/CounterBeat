# CounterBeat - M0 feel playtest (about 15 minutes)

Creator notes on the current (unchanged) build, copied verbatim.

## Notes

**Loading and first impression** (how long did it take, anything confusing?): all good, maybe a better ui design (Fonts, layout etc)

**Counter-strafe stop** (can you tell when you have stopped? does the grade feel fair?): yes the movement mechanism is good

**Timing** (do hits feel early/late? does the beat line up with the music? any audio lag?):all good

**Aim** (too strict, too loose, spread penalty noticeable?): also good

**Readability** (approach ring, note highway, HUD - what did you look at? what competed for attention?): seems fine

**Feedback / juice** (what felt satisfying? what felt flat?): the movment and shooting is satisfying, the design is a little basic

**Difficulty** (Normal vs Hard - did they feel different?):yes

**The single worst feel problem:** can feel a bit janky/jittery and its a website

**The single best moment:** the hs sound is satisfying

**Anything else:**
- seems good just work towards making it more professional and try not to add too much clutter

## How to repeat it

```
npm install
npm run build
npm run preview     # http://localhost:4173/game.html
```
Run order: tutorial once; one track on Normal then Hard; one fast track (150 or 170 BPM) on Normal. Repeat after M7 and compare.
